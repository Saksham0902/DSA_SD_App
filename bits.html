    Five tricks that do everything

    XOR cancels pairs, n & (n − 1) erases a bit, x & −x isolates one, shifts move bits around, and masks test them.

    Think in columns of bits

    Bitwise operators work on every bit position independently. & keeps bits set in both, | keeps bits set in either, ^ keeps bits set in exactly one. That last one is the star: a ^ a = 0 and a ^ 0 = a, so XOR-ing a list makes every pair vanish.

    Masks: a number is a subset

    n bits can stand for n yes/no choices. Count from 0 to 2ⁿ − 1 and you've listed every subset.

    Every subset is a number

    With items [a, b, c], the mask 101 means “take a and c”. Looping mask from 0 to 7 visits all 8 subsets with no recursion. Bit i is in the subset when mask >> i & 1 is 1. The same idea powers bitmask DP, where a whole set of visited nodes fits into one integer.

    Counting the cost

    Fixed-width integers make most bit tricks O(1), and loops over bits O(log n).

    How to price a bit-manipulation solution

    1. Single operations (&, |, ^, ~, shifts) on a machine word are O(1).
    2. Looping over the bits of n runs once per bit: ⌊log₂ n⌋ + 1 times → O(log n), which is O(32) = O(1) for 32-bit ints.
    3. Kernighan's trick n &= n - 1 runs once per set bit: even fewer.
    4. Over a range 0…n multiply by n, or reuse answers: bits[i] = bits[i >> 1] + (i & 1) → O(n).
