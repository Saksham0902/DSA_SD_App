DSA roadmap

Topics build on each other in this order. Recursion sits in the middle because trees, backtracking, graphs and DP all depend on it. Every topic ends with a “Counting the cost” chapter on time and space complexity.

System design roadmap

Start with design thinking: the one idea behind every design, how to read UML, and a map of how everything links. Then Java and OOP, SOLID and the patterns (each built as a class diagram, step by step), the LLD problems, the building blocks, and finally the HLD classics drawn box by box.
